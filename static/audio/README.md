# 外接音效與雙語語音系統說明 (Audio & Speech Assets)

> **最後更新**：2026-11-22（v3.1 四大主學科雙語語音・英文兩側圖卡點讀・數學注音助讀版）

本專案具備「零相依內建 Web Audio 合成音效 + Web Speech 真人雙語朗讀」與「外接音效檔案優先」的雙層架構，全面支援 **國語注音、英文樂園、數學城堡、99乘法表** 四大科目。

## 1. 內建雙語真人語音 (Web Speech API)
- **台灣國語語音 (`zh-TW`)**：自動匹配 macOS `Meijia (美佳)` 或 Windows `Microsoft Hanhan / Yating`，用於朗讀國語注音字詞、數學評量題目、99 乘法口訣與英文單字之中文解釋。
- **美式英語語音 (`en-US`)**：自動匹配自然英語發音（如 `Samantha`、`Karen`），用於朗讀英文 A-Z 字母、Phonics 自然發音與生活單字，並在朗讀英文後自動伴隨中文意思說明。

## 2. 如何外接自訂音效？
您可以直接將自訂的 MP3 / WAV 檔案放置於此資料夾（`static/audio/`），系統會自動優先載入播放：

1. `correct.mp3` - 答對過關時播放的勝利音效 / 拍手歡呼聲。
2. `wrong.mp3`   - 答錯或溫和提示時播放的提示聲。
3. `pop.mp3`     - 點擊按鈕或拖曳注音方塊時的清脆彈跳聲。
4. `win.mp3`     - 連續過關的額外慶祝音效。

> **備註**：若此目錄為空，系統會自動無縫使用瀏覽器原生的 **Web Audio API 即時合成音**（含泡泡破裂聲、小錘子敲擊聲、過關和弦），無需下載任何外部音檔即可正常運作。
