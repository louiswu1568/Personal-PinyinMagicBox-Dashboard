# 小小魔法學習樂園 — 注音魔法盒 (Pinyin Magic Box v3.0) 🪄 🎀

> **版本**：v3.0  
> **教學對齊標準**：**河堤國小 × 康軒文教（國小一年級 一上・一下「學習評量」與「新挑戰測驗卷」）**  
> **涵蓋四大核心學科**：🪄 **國語注音 (3,000題)** ｜ 🔤 **英文樂園 (229題)** ｜ 🔢 **數學城堡 (346題)** ｜ ✖️ **99乘法表 (407題)**  
> **v3.0 學習核心**：📦 **Leitner 四格錯題間隔複習** ｜ 🎯 **每回 30 題無重複組卷** ｜ ⏰ **每日 30 分鐘計時提醒** ｜ 👑 **寵物/貼紙/故事階段式獎勵** ｜ 📊 **線上直出 HTML 家長週報**

專為國小一年級（6~8 歲）學童量身打造的**「四合一學科互動評量與期中、期末考反覆練習平台」**，支援本地端與 **Vercel (`vercel.app`)** 雲端無狀態部署。

---

## 🌟 核心特色

1. **四大主題學習館（共 3,982 題）**：
   - **🪄 國語注音（3,000 題 + 6 種互動遊戲）**：魔法拼音盒、泡泡消消樂、聲調小怪獸、極速小賽車、記憶翻翻牌、地鼠敲注音。
   - **🔤 英文樂園（229 題）**：A–Z 大小寫配對、Phonics 自然發音、教室用語與主題單字（全選項中英雙語對照）。
   - **🔢 數學城堡（346 題）**：數與量、比大小與圖形、分與合（湊十拆十）、20 以內加減、看時鐘與超市購物找零。
   - **✖️ 99乘法表（407 題）**：2/5/10 跳數、生活應用乘法、圖形陣列與 1~9 互動口訣朗讀。
2. **v3.0 有效且快樂的學習核心**：
   - **Leitner 四格記憶盒與錯題本**：自動記錄錯題並按 1 / 3 / 7 / 14 天間隔安排複習，答錯即時顯示兒童友善的「💡 魔法解析」。
   - **每回合 30 題智慧組卷**：優先抽考到期與易錯題（≤ 40%），搭配新題（≥ 60%），首題正解絕不固定在第 1 項，連續兩題正解位置不重複。
   - **每日 30 分鐘溫馨計時**：即時顯示今日學習時間，滿 30 分鐘溫和提醒休息，不強制中斷。
   - **階段式獎勵與線上家長週報**：收集星星解鎖寵物、貼紙與有聲故事；於「⚙️ 設定」中可一鍵開啟或下載完整 HTML 家長週報。

## 🚀 部署至 Vercel 或本地執行

### 1. Vercel 一鍵部署
本倉庫已內建 `vercel.json`，直接在 [Vercel](https://vercel.com) 匯入本倉庫 (`Personal-PinyinMagicBox-Dashboard`) 即可自動完成部署，無須額外設定環境變數。

### 2. 本地端啟動
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
# 開啟瀏覽器訪問 http://localhost:8000
```
